# MakeFun Joke Entry

This repository contains a simple Node.js program (`main.ts`) that generates a specific entry joke for the MakeFun competition 'the-joke-about-the-demo-20261123-0112'.

The joke text is: 'Of course it works on my machine, because my machine is not currently being watched by twelve investors and a live cursor.'

## Usage
The program is executed using Node.js and writes the joke to `./output/entry.txt`.
